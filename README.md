# 🍄 Составление отчётов для лабораторных по КСПБД

В данном репозитории будут публиковаться материалы для создания отчётов по лабораторным по КСПБД по мере их выполнения.

## 📖 Короткий гайд по структуре репозитория

В репозитории находятся следующие каталоги:  
- ***guides***  
Содержит методические указания к лабораторным работам в формате .pdf. Обновляется по мере получения новых методичек от преподавателей.  
- ***labs***  
Содержит материалы по выполненным лабораторным (скриншоты, код, бэкапы БД и т. д.). Обновляется по мере выполнения работ. Номера подкатологов соответствует номерам работ.

Каждый пронумерованный каталог из *labs* содержит следующие подкаталоги:  
- ***screenshots*** — Скриншоты процесса выполнения работы  
- ***code*** — Скрипты SQL-запросов, использованных при выполнении работы  
- ***backups*** — Бэкапы БД, использованных в работе

### ❗️*Важно:*
> В каталогах с материалами может содержится файл *info.txt*. В данном файле содержится информация о том, как должны быть использованы файлы каталога в отчёте.

## 🐘 FAQ по pgAdmin

### ❓Как восстановить БД из бэкапа?
> Необходимо создать новую БД, кликнуть по ней пкм, выбрать *Восстановить* &rarr; *Имя файла*`<путь к файлу .backup>` &rarr; *Специальный или tar* &rarr; *Восстановить*  
После этих действий в созданной нами базе данных появятся необходимые таблицы.

***🚫ВНИМАНИЕ, МОГУТ ВОЗНИКНУТЬ ПРОБЛЕМЫ С ВЕРСИЯМИ!🚫***

### ❓Как выполнить часть SQL-скрипта, а не весь целиком?
>Для выполнения отдельных запросов из всего скрипта нужно всего лишь выделить необходимую часть кода и нажать кнопку ***Run(F5)***

💡***ЛАЙФХАК:***  
>*Если выделять код с зажатой клавишей* ***Alt,*** *то текст будет выделяться не построчно, а прямоугольной областью, что может быть очень полезно, например, при необходимости убрать из скрипта данные целого столбца.*
