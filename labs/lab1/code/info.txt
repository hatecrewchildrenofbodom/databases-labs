script_for_creation.sql - Скрипт создания БД.
В начале файла имеется закомментированная строчка:
--CREATE DATABASE ethnic_composition;
Эта строчка нужна для создания самой БД. Через pgAdmin базу данных лучше создать вручную и выполнить незакомментированную часть скрипта.
Другой путь - раскомментировать строку, выполнить сперва ее, а затем оставшийся код
